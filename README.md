# Parser C&C

Telegram-бот с Mini App для поиска бизнесов, которым нужен сайт или Telegram-бот, по открытым данным карт и сайтам самих компаний. Mini App основана на присланном файле `index_1.html`; бот, API и интерфейс связаны. Результаты и статусы хранятся в SQLite.

**Для Railway + Vercel откройте [DEPLOY_RAILWAY_VERCEL.md](DEPLOY_RAILWAY_VERCEL.md).** В этой схеме Railway запускает бот/API и хранит SQLite на подключённом volume, а Vercel отдаёт Mini App и проксирует запросы API.

## Что умеет проект

- ищет бизнесы, которым нужен сайт или Telegram-бот: 10 готовых ниш (барбершопы, салоны красоты, маникюр, автосервисы, стоматологии, фитнес, кофейни, рестораны, ветклиники, языковые и детские школы) и своя ниша по слову; на каждую нишу — несколько запросов (теги карт + поиск по названию);
- проверяет каждый бизнес вживую: открывается ли сайт, HTTPS, мобильная версия, скорость, форма заявки, онлайн-запись и бронирование (YCLIENTS, DIKIDI, Booksy, Fresha, Restoplace и др.), Telegram и Telegram-бот, контакты на сайте и на странице «Контакты», актуальность;
- классифицирует: нет сайта · сайт не работает · слабый сайт · нужен редизайн · нормальный сайт, но нужен бот;
- ставит приоритет 0–100 с объяснением, например: «Сайт отсутствует, есть телефон и Instagram, Telegram-бот не найден.»;
- **никогда не выдаёт один бизнес двум людям**: совпадение по телефону, домену, email, Telegram, Instagram, ВК, WhatsApp, ID в источнике, названию+адресу или названию+координатам = тот же бизнес. Закрепление атомарное (одна транзакция SQLite), проверено на 100 одновременных запросах;
- пробный доступ для всех: 1 поиск до 10 лидов, затем сообщение о C&C Family с кнопками «Вступить в команду», «Докупить запросы» и контактом;
- ключи доступа, бан, бонусные запросы, лимиты — в админ-панели и командами бота;
- вкладка «Скрипты»: по 5 скриптов на каждую нишу (первое, короткое, подробное, звонок, повторное), копирование, правка, генерация новых; в карточке лида — «Сгенерировать скрипт» по реальным данным бизнеса;
- кнопка «Какие ниши сейчас требуют сайт/бот?» — статистика по реальным проверкам (показывается, только когда данных достаточно);
- Excel-выгрузка со всеми полями анализа.

## Что получает участник (режим по умолчанию)

По решению владельца бот не показывает данные, которые часто устаревают в картах (сайт, ссылки ВК/Instagram/Telegram). Каждый лид — это:

- название, ниша, город и адрес;
- телефон из карточки на карте (если номеров несколько — остальные открываются стрелочкой рядом с номером);
- кнопка **«Открыть на карте»** — открывает карточку самого бизнеса (Яндекс Карты для СНГ, Google Карты для остальных стран), где видны сайт, соцсети, отзывы и часы работы;
- кнопка «Скрипт» и статусы.

Бизнесы без телефона в выдачу не попадают. Поиск идёт быстро, потому что сайты не открываются. Полную проверку сайтов, Telegram, ВК и Instagram можно включить переменной `ANALYZE_SITES=1`.

Кнопка «Какие ниши требуют сайт/бот?» показывает оценку нейросети по нашим нишам для выбранной страны (кешируется на сутки). Без ключа Gemini — базовая оценка.

## Страны и города

14 стран: Россия, Украина, Беларусь, Казахстан, Узбекистан, Кыргызстан, Армения, Азербайджан, Грузия, Молдова, Польша, Литва, Германия, ОАЭ (список и крупные города — в `countries.py`).

- Можно вписать **любой** город или район — он находится через геокодер OpenStreetMap.
- Если город не указан, парсер обходит крупные города страны по очереди (до 4 за поиск), каждый раз начиная с другого города, поэтому повторные поиски охватывают разные города. Огромный запрос «по всей стране» сервер карт часто не успевает выполнить, поэтому так надёжнее.
- Если один город не нашёлся или сервер не ответил, поиск продолжается по остальным.
- Телефоны проверяются по правилам номеров каждой страны. Для бизнесов в Польше, Литве, Германии и ОАЭ нейросеть пишет скрипт на местном языке с переводом на русский.
- Для своей ниши слово ищется и с большой, и с маленькой буквы («Шиномонтаж» и «шиномонтаж»), в нишах есть местные слова (fryzjer, Zahnarzt, kirpykla и т. п. через теги карт).

## Честность данных

- Ничего не придумывается. Нет данных — «не найдено», не удалось проверить — «не удалось проверить».
- Сайт, который не дал себя проверить (таймаут, защита от ботов 403/429/503), не считается «сломанным»: такой лид не выдаётся.
- Ссылки Telegram проверяются на публичной странице t.me; несуществующие не показываются. Неработающий сайт показывается текстом, без ссылки.
- Телефоны проверяются по правилам номеров страны. Лиды без телефона и мессенджеров не выдаются.
- CAPTCHA, антиботы и платные ограничения не обходятся.

## Источники (бесплатные)

| Источник | Ключ | Что даёт |
|---|---|---|
| OpenStreetMap (Overpass, 3 сервера по очереди) | не нужен | организации, телефоны, сайты, соцсети, часы работы |
| Geoapify Places | бесплатный, без карты | запасной канал к тем же данным OSM, когда Overpass перегружен; 3000 кредитов в день, парсер сам не превышает `GEOAPIFY_DAILY_CREDITS` |
| Сайты самих компаний | — | контакты, Telegram, бот, онлайн-запись, форма |
| Google Places | платный после 1000 запросов, нужна карта | **выключен по умолчанию**; включается только ключом `GOOGLE_PLACES_API_KEY` |

Каждый источник — отдельный адаптер: если один недоступен, поиск идёт по остальным, а ошибка видна в админ-панели («Ошибки»). 2ГИС и Яндекс Карты не подключены: их контакты доступны только платно.

### Как получить ключ Geoapify (бесплатно, 2 минуты)

1. Зарегистрируйтесь на [myprojects.geoapify.com](https://myprojects.geoapify.com) (карта не нужна).
2. Создайте проект, скопируйте API key.
3. В Railway → Variables добавьте `GEOAPIFY_API_KEY` и сделайте Redeploy.

### Нейросеть для скриптов: Google Gemini (бесплатный уровень)

DeepSeek API бесплатным не является (работает по предоплате), поэтому подключён Google Gemini API — у него есть бесплатный уровень без банковской карты.

1. Откройте [aistudio.google.com/apikey](https://aistudio.google.com/apikey), войдите Google-аккаунтом, нажмите **Create API key**.
2. В Railway → Variables добавьте `GEMINI_API_KEY` (или `AI_PROVIDER` + `AI_API_KEY` для DeepSeek / Groq / OpenRouter). Модель по умолчанию — `gemini-3.5-flash-lite` (можно сменить в `GEMINI_MODEL`).
3. Лимиты расхода: `AI_DAILY_LIMIT` (всего в день) и `AI_USER_DAILY_LIMIT` (на человека). Если ключа нет, лимит кончился или сервис не ответил — скрипт собирается из шаблона по данным лида, пользователь всё равно получает текст.

На бесплатном уровне Google может использовать запросы для улучшения своих моделей; в запрос уходят только публичные данные бизнеса (название, город, что найдено), без данных пользователей бота.

## Доступ

- Каждый, кто открыл бота, получает пробный доступ: `TRIAL_SEARCHES` поисков (по умолчанию 1) по `TRIAL_LEADS` лидов (10). Пустой поиск не списывается.
- После пробы бот присылает сообщение о C&C Family (ссылка `JOIN_URL`, контакт `CONTACT_USERNAME`).
- Полный доступ выдаёт владелец: в админ-панели (по @username или ID), командой `/adduser`, или ключом `/newkey` — пользователь вводит его в приложении или командой `/key`.
- «Докупить запросы»: владелец добавляет бонусные поиски (`/bonus @user 5` или кнопки в админке).

## Локальный запуск

Требуются Windows и Python 3.12. В PowerShell:

```powershell
cd "C:\Users\MakeMyCry\Desktop\parser_cc"
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
.\.venv\Scripts\python.exe main.py
```

В локальном `.env` укажите `BOT_TOKEN`. Сначала оставьте `ADMIN_IDS` пустым, запустите бота и отправьте `/id`. Остановите сервис `Ctrl+C`, внесите свой Telegram ID в `ADMIN_IDS` и перезапустите. Для запуска Mini App локально нужен HTTPS-туннель; развернутый запуск описан в [руководстве для Railway и Vercel](DEPLOY_RAILWAY_VERCEL.md).

## Команды

- `/start` — приветствие, статус доступа и кнопка Mini App;
- `/app`, `/stats`, `/export`, `/id`;
- `/key КОД` — активировать ключ доступа.

Только владельцу из `ADMIN_IDS`:

- `/adduser ID` или `/adduser @username 100` — полный доступ (и лимит);
- `/deluser ID` — вернуть на пробный режим;
- `/limit ID ЧИСЛО` — дневной лимит;
- `/bonus @username 5` — добавить поисковые запросы;
- `/newkey`, `/newkey 100`, `/newkey @username 100` — создать ключ доступа;
- `/ban @username`, `/unban @username`;
- `/users`, `/broadcast ТЕКСТ`.

Всё то же есть в админ-панели Mini App: пользователи, ключи, все лиды, статистика по нишам и городам, чёрный список бизнесов, ошибки источников, рассылка. Стандартные скрипты владелец правит прямо во вкладке «Скрипты».

## Тесты

```bash
python -m unittest discover -s tests
```

80 тестов: один бизнес из 5 источников = 1 лид; лид A не попадает к B; повторный поиск без старых лидов; 100 одновременных запросов без дублей; 11-й лид на пробе запрещён; ошибка источника не ломает поиск; недоступный сайт; битые контакты; функции бота; API админки.

## Важные ограничения

- Результаты зависят от полноты OpenStreetMap и доступности Overpass, Nominatim и сайтов.
- Сервис использует публичные данные; он не входит в аккаунты соцсетей и не выдумывает контакты. Nominatim имеет ограничения по частоте и использованию: соблюдайте [политику OpenStreetMap Foundation](https://operations.nominatim.org/policies/nominatim/).
- Проверка сайтов блокирует локальные и зарезервированные IP-адреса, проверяет адреса перенаправлений и использует TLS-проверку. Это снижает риск запросов к внутренним ресурсам, но не обещает абсолютную неуязвимость.
- Telegram `initData` проверяется на сервере и принимается только при корректной подписи и возрасте не более часа.
- Для production на Railway подключите volume `/data`; без него SQLite-файл не переживёт пересоздание контейнера.


## Что нового в версии 3

- Города: `cities.json` — 60–150 городов на страну (от крупных к маленьким) с координатами из OpenStreetMap. Геокодер для них не нужен, поиск стартует сразу.
- Скорость: запрос уходит сразу на несколько зеркал OpenStreetMap, берётся первый ответ; ответы кэшируются в базе на 4 дня; в быстром режиме карты сразу отдают только бизнесы с телефоном; если в центре мало — район расширяется один раз.
- Картинки CLOSE / OPEN (`assets/`) приходят вместе с сообщениями о закрытом и открытом доступе.
- Админка: вкладка «Участники» (кто запускал бота и открывал ли мини‑апп), удаление участника (бан + скрыт из списков), рассылка с картинкой и жирным/курсивом.
- Excel: только Название, Ниша, Страна, Город, Адрес (ссылка на Яндекс Карты), Номер телефона, Статус.
